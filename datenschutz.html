Datenschutz

n8n privat greift nur auf das eigene Gmail-Konto des Betreibers zu, um Mails zu sortieren und zu beschriften. Die App hat keine anderen Nutzerinnen oder Nutzer.

Die Daten werden ausschliesslich auf einem eigenen Server in Deutschland verarbeitet. Sie werden nicht an Dritte weitergegeben, nicht verkauft und nicht für Werbung verwendet.

Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy, einschliesslich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen.
